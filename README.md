A spot-the-difference game for the [best-spot-the-difference-game-20261121-0451 bounty](https://make.fun/bounty/best-spot-the-difference-game-20261121-0451).

Two pictures of the same sunny garden sit side by side — but seven things changed between them. Click a difference on either picture to circle it on both. Find all seven before the 2-minute timer runs out; a wrong click costs 3 seconds, and two hints are there if you get stuck — each hint circles one difference you haven't found yet. Score: 100 points per difference found, plus a time bonus when you win.

Play it: serve `game/` with any static server and open `game/index.html` in desktop Chrome. No network, no build step — plain HTML, CSS and canvas JavaScript.
